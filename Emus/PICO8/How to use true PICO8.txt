So, it looks like the true PICO-8 is a paid program.  By default, this will run the fake-08 system.  If you would like the true PICO-8 system by default, delete "config.json" and rename "config.json.real" to "config.json".  You will also need to place pico8.dat & pico8_64 into "/PICO8_Wrapper/bin".  You can find them on the internet.
